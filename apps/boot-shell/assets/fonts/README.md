# ArchRescue typefaces

- Geist Regular, SemiBold and Bold are the unmodified static TTFs from Vercel's `geist` 1.9.2 package. [Upstream project](https://github.com/vercel/geist-font)
- IBM Plex Mono Regular is the unmodified TTF from IBM Plex commit `48e8676114c04f29033b4b53da4ec579f8846297`. [Upstream source](https://github.com/IBM/plex/blob/48e8676114c04f29033b4b53da4ec579f8846297/packages/plex-mono/fonts/complete/ttf/IBMPlexMono-Regular.ttf)

Both fonts use the SIL Open Font License 1.1. The adjacent license files cover the embedded copies.

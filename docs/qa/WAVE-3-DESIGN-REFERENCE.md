## Native rendering notes

The application uses the specified #0E0E13 background, #16161E panels, #F7F6FB text, #C3A8FF actions and focus, #83E8AA verified status, #FFCC80 warnings and #FFA0A6 errors. Shared owner-drawn controls and cards use GDI. The dirty paint rectangle uses a compatible memory bitmap and releases it after copying to the native paint DC. Native edit, combo and list controls retain text handling, focus, keyboard navigation and scrolling.

WinPE supplied Tahoma and lacked the regular Segoe UI file in the tested image. The regular Tahoma fallback keeps the hierarchy readable. The exact reference font metrics, gradient accents and system title-bar color differ. Native arrow buttons and scrollbars use the host style. The compact rail uses short captions at 800×600 and keeps fixed actions above the footer. The assisted-mode caption and deployment-plan export caption can ellipsize at that width. The actual export remained reachable and produced a valid plan. The technical report records the actual viewport and input tests, including the remaining scaling and scenario coverage.
